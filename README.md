# Welcome to Todo List project by Axum (Rust Language)

Hi! This is my first project developing a web API service in **Rust**.

I chose **Axum** as my framework because it's similar to Express, which I'm familiar with from my experience with TypeScript and NodeJS.

This is a sample project created to support my college coursework, featuring a Todo List Vue frontend that interacts with a Rust API backend. The project also includes benchmarks to analyse the memory usage and performance characteristics of this implementation.
